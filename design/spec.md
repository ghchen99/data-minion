# AI-Powered Dataset Workspace with Agent-Driven NLP Interaction

## 1. Problem Statement

Non-technical and semi-technical users struggle to extract value from
raw CSV datasets without specialized tools (Excel, Python, SQL, BI
software) or data expertise. Even technical users face friction when
performing repetitive data cleaning, generating reports, or building
dashboards.

There is a need for a unified AI-driven platform where users can:

-   Upload CSV datasets
-   Interact with them using natural language
-   Automatically generate derived artifacts (cleaned datasets,
    analytics reports, visualizations, dashboards)
-   Persist and manage outputs across agent interaction threads
-   Download results in standard formats

The platform should use an AI agent that orchestrates dataframe
operations and artifact generation through tool calls.

------------------------------------------------------------------------

## 2. Objectives

-   Enable natural language interaction over uploaded CSV datasets.
-   Use an AI agent to simulate dataframe operations via structured tool
    calls.
-   Persist outputs as versioned artifacts tied to interaction threads.
-   Allow users to download cleaned tables, reports, and dashboards.
-   Provide a workspace model where each dataset acts as a container for
    artifacts and agent runs.

------------------------------------------------------------------------

## 3. Target Users

-   Business analysts

-   Researchers
-   Students
-   Product managers

## 4. Core Concepts

### 4.1 Dataset

A **Dataset** is a top-level container created when a user uploads a CSV
file.

**Dataset Properties**

-   id
-   name
-   original_file
-   schema
-   created_at
-   owner_id
-   threads\[\]
-   artifacts\[\]

Datasets are visible on the homepage.

------------------------------------------------------------------------

### 4.2 Thread (Agent Run Context)

A **Thread** represents a conversation between the user and the AI agent
about a specific dataset.

Each thread:

-   Contains user prompts
-   Contains agent reasoning and tool calls
-   Produces one or more artifacts
-   Is persisted and replayable

Threads allow users to:

-   Revisit past analyses
-   Branch from previous results
-   Maintain contextual continuity

------------------------------------------------------------------------

### 4.3 Artifact

Artifacts are structured outputs generated by the agent.

**Artifact Types**

#### Cleaned Dataset

-   Modified dataframe  
-   Exportable CSV
-   Versioned snapshot

#### Analytics Report

-   Narrative explanation
-   Statistical summaries
-   Markdown / PDF export

#### Visualizations

-   Charts (bar, line, histogram, scatter, etc.)
-   PNG / SVG export

#### Dashboard

-   Multi-chart layout
-   Interactive filters
-   Exportable (HTML bundle)

#### Derived Dataset

-   Aggregated tables
-   Feature-engineered datasets

Each artifact:

-   Is tied to a thread
-   References its source dataset
-   Stores tool execution lineage
-   Can be downloaded

## 6. AI Agent Architecture

### 6.1 Agent Role

The AI agent acts as:

-   Data analyst
-   Data cleaner
-   Visualization builder
-   Report writer

It uses tool calls to simulate dataframe operations.

------------------------------------------------------------------------

### 6.2 Tooling Model (Simulated Dataframe Ops)

Tool calls may include:

-   load_dataframe(dataset_id)
-   describe_dataframe()
-   clean_missing_values(strategy)
-   drop_columns(columns)
-   filter_rows(condition)
-   groupby_aggregate(group_cols, metrics)
-   create_visualization(type, params)
-   generate_report(summary_stats, visuals)
-   export_csv(dataframe_id)
-   build_dashboard(charts\[\])

Each tool call:

-   Is logged
-   Returns structured JSON
-   Updates internal dataframe state

------------------------------------------------------------------------

### 6.3 Agent Loop

1.  User submits prompt
2.  Agent:
    -   Parses intent
    -   Plans steps
    -   Executes tool calls
    -   Iteratively refines
    -   Produces artifact(s)
    -   Stores results
3.  Returns explanation + preview
